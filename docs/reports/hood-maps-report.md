### 3. Анализ архитектуры и логики

Анализ проводился через вкладки Network и Sources инструментов разработчика Chrome.

**Веб-сервер / CDN:** сайт стоит за Cloudflare — заголовок ответа `Server: cloudflare`, `Cf-Cache-Status: HIT`. Это означает что страницы отдаются из кэша Cloudflare, а реальный сервер скрыт за прокси.

**Бэкенд:** язык и фреймворк бэкенда определить не удалось — заголовок `X-Powered-By` отсутствует, намеренно скрыт Cloudflare. Косвенный признак — структура API-запросов вида `?action=get_data&slug=new-york-city` и `?action=get_places&city_slug=new-york-city`, что характерно для PHP, однако утверждать это однозначно нельзя.

**Картографическая библиотека:** MapLibre GL JS версии 5.6.0 — определено по имени файла `maplibre-gl-5.6.0.js` во вкладке Network (фильтр JS). Это open-source форк Mapbox GL JS, карта рендерится через WebGL в элемент `<canvas>`.

**JS-библиотека:** jQuery 3.5.1 — файл `jquery.js` виден во вкладке Network, версия подтверждена в консоли командой `$.fn.jquery`, которая вернула `"3.5.1"`.

**JS-фреймворк:** отсутствует. В списке загруженных скриптов нет React, Vue или Angular. Код в Sources написан на Vanilla JS с использованием jQuery.

**Формат данных API:** сервер возвращает JSON (`Content-Type: application/json`) и GeoJSON-файлы для данных карты, `.pbf` — векторные тайлы карты в формате Protobuf.

**Защита от ботов:** Cloudflare Turnstile — обнаружено в коде файла `index.js` (`window.hmTurnstile`), используется вместо reCAPTCHA при добавлении меток.

### 4. Семантические элементы HTML5 и CSS-классы

Страница построена преимущественно на `<div>`-ах — семантические теги HTML5 (`<main>`, `<article>`, `<section>`, `<nav>`) практически не используются. Это снижает доступность для скринридеров и поисковых роботов.

При этом CSS-классы на `<div>`-элементах именованы осмысленно и отражают содержимое блока, а не его внешний вид:

| Класс | Назначение |
|---|---|
| `class="neighborhood-display"` | Блок отображения названия района |
| `class="action-draw-mode active"` | Кнопка режима рисования (с модификатором активного состояния) |
| `class="action-enable-gps"` | Кнопка включения геолокации |
| `class="zoom-buttons"` | Блок кнопок масштабирования карты |

Классы описывают смысл и функцию элемента — это хорошая практика при div-вёрстке, однако не заменяет семантические HTML-теги.

### 5. Адаптивность

Ресурс адаптивен. Проверка проводилась через режим Device Toolbar в DevTools (Ctrl+Shift+M) — при уменьшении ширины экрана интерфейс перестраивается: панели управления сворачиваются, карта занимает весь экран. Сайт корректно отображается как на десктопе, так и на мобильных устройствах.

### 6. Анализ с помощью Lighthouse

**Условия проверки:** домашняя сеть Wi-Fi, ПК, браузер Chrome, режим Desktop.

| Категория | Балл |
|---|---|
| Performance | 31 |
| Accessibility | 81 |
| Best Practices | 100 |
| SEO | 92 |

**Комментарий по результатам:**

Performance 31 — низкий показатель. Основная причина — тяжёлая библиотека MapLibre GL JS (рендеринг карты через WebGL), которая существенно увеличивает время загрузки страницы. Это типичная проблема картографических сервисов.

Accessibility 81 — приемлемый результат, однако есть замечания. Вероятная причина потерь — отсутствие семантических HTML-тегов и ARIA-атрибутов на интерактивных элементах.

Best Practices 100 — отличный результат, сайт следует всем современным техническим стандартам безопасности и качества кода.

SEO 92 — хороший показатель, страница хорошо оптимизирована для поисковых систем.

### 7. Маркетинговые инструменты и аналитика

Поиск проводился во вкладке Network с поочерёдной фильтрацией по ключевым словам: `analytics`, `metrika`, `facebook`, `pixel`, `tagmanager`, `hotjar`.

По всем фильтрам запросы к сторонним маркетинговым сервисам не обнаружены. Сайт не использует счётчики и пиксели отслеживания. Это осознанная позиция автора проекта (Pieter Levels) — минимальный сбор данных о пользователях без трекинга.
